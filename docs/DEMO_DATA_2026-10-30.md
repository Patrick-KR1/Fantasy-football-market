# 사용자·거래·커뮤니티 샘플 데이터

사용자의 요청으로 실제 운영 DB에 샘플 데이터를 추가했다. 기존 이용자의 자료와 구분되도록 닉네임에 `_샘플`, 프로필과 Auth 관리자 메타데이터에 `kickx-demo-20261030` 표시를 뒀다.

## 구성

- 사용자 50명. 5대 리그마다 10명씩, 응원 구단은 현재 DB에 있는 14개 구단에 나눠 배정했다. 일부는 서로 다른 리그의 구단을 함께 선택한다.
- 각 계정의 초기 자금은 실제 서비스 정책과 같은 1,300,000P다. 여러 구단의 선수를 섞어 보유하고, 일부는 매도까지 진행한다.
- 거래는 현재가·거래 가능 시간·잔액·중복 보유·매도 수수료 2%를 검사하는 기존 함수로 체결한다. 임의의 과거 매입가나 수익을 만들어 넣지 않는다.
- 선수 게시글 50개, 구단 게시글 50개. 수집된 최근 정규 리그 경기의 날짜·스코어·출전 시간·Performance·득점/도움 등 확인된 지표를 사용한다.
- 댓글 100개와 답글 20개. 구단 글의 작성·댓글 권한은 해당 응원 구단 기준을 따른다.
- 일부 글에는 작성자 본인의 실제 생성된 매수 또는 매도 영수증을 연결한다. 관심 목록도 함께 채운다.

계정은 로그인 차단 상태로 생성하며 로그인용 비밀번호를 발급·공유하거나 소셜 로그인을 연결하지 않는다. 사용자 초대나 확인 메일을 발송하지 않는다. 샘플이 실제 이용자처럼 오인되지 않도록 공개 닉네임 표시를 유지한다.

## 글의 근거와 말투

근거 자료는 `data/demo/source-20261030.json`의 운영 DB 조회 결과다. 날짜는 KST로 표시하고, 실제 확인하지 않은 부상·이적·선발 예측을 사실처럼 쓰지 않는다. 0분 미출전과 실제 출전 점수는 구분한다.

글은 기록 메모, 보유 고민, 수수료 경험, 응원 구단 잡담 등으로 나누고 문장 길이·말투·기록 표현을 달리했다. 샘플 생성 과정에서 축구 API나 AI 생성 API는 호출하지 않는다.

## 재실행과 검증

`node scripts/seed-demo.mjs`는 DB를 변경하지 않고 미리보기 JSON만 만든다. `--apply`를 붙이면 관리자 서비스 키가 있는 실행 환경에서 반영한다. `.github/workflows/sample-data.yml`은 개인 저장소에서만 실행한다.

계정 ID와 거래·게시글·댓글 요청 ID는 고정된 입력으로 생성한다. 재실행은 같은 계정과 요청을 재사용하고, 다른 계정의 거래·잔액·보유에는 접근하지 않는다. 샘플 전용 함수는 서비스 역할만 호출할 수 있고 일반 사용자는 프로필의 샘플 표시를 설정할 수 없다.

검증은 거래 원장 합계와 지갑 잔액 일치, 마지막 매입과 현재 보유의 대응, 수수료 일치, 본인 거래 첨부, 구단 응원 권한, 답글 연결, 기존 사용자 금융 자료의 변경 여부를 포함한다.

샘플 수치와 검증 근거는 [운영 결과 JSON](evidence/demo-data-2026-10-30.json)에 있다. 샘플을 나중에 정리할 때에는 프로필과 Auth 메타데이터의 배치 표시를 함께 확인해야 하며, 실사용자의 자료를 일괄 삭제하지 않는다.

## Claude 화면 작업 인계

추가 화면 구현 없이 기존 커뮤니티·선수 상세·거래 첨부·랭킹을 통해 샘플을 볼 수 있다. 구단 커뮤니티에는 구단 글 50개, 선수별 커뮤니티에는 해당 선수 글이 분산된다. 거래 첨부 35개는 저장된 실제 샘플 거래 영수증을 사용한다. 공개 작성자 이름의 `_샘플` 표시는 유지한다.

글은 2026-10-30에 수집한 기록을 바탕으로 작성한 고정 샘플이다. 글 내용이 이후 경기마다 자동 갱신되지는 않는다. 본문 100개 모두 실제 줄바꿈이 저장돼 있으며 거래 금액·수수료·보유 상태는 서버 데이터로 표시한다.

샘플 계정은 로그인할 수 없으므로 계정 전환용 버튼이나 비밀번호를 만들지 않는다. 미리보기 원본은 `node scripts/seed-demo.mjs`로 생성할 수 있다. 생성 로직은 `scripts/lib/demo-content.mjs`, DB 반영은 `scripts/seed-demo.mjs`, 권한은 `supabase/migrations/20261030134723_sample_accounts_seed.sql`을 참고한다.

# KICK-X 클로드 디자인 결과: 헤더 커서·가치 변동 연출 (2026-11-24)

- 기준: `main` `89e8aff`.
- 바꾸지 않은 것: 서버, SQL, API, 가격·변동률 계산. 연출은 서버가 준 `price`, `change` 값을 그대로 표시한다.

## 변경

1. 헤더 메뉴 커서 깜빡임
   - 헤더 링크와 버튼(포인트 상점 등)을 클릭하면 텍스트 커서가 깜빡이던 문제를 고쳤다.
   - 헤더 링크와 버튼에 `caret-color: transparent`와 `user-select: none`을 넣었다.
   - 파일: `app/styles/updates-1121b.css`.
2. 가치 변동 연출을 전광판 방식으로 다시 만들었다.
   - 지운 것: 빛살, 광택, 떠다니는 화살표, 블러 배경. 흔한 AI풍 장식이다.
   - 카드 맨 위 색 띠에 방향을 먼저 보여 준다:
     - 상승: 초록 띠, `가치 상승`, ▲ 변동률.
     - 하락: 빨간 띠, `가치 하락`, ▼ 변동률.
     - 변동 없음: 회색 띠.
   - 현재 가치 숫자도 같은 색으로 칠한다.
   - 움직임도 방향에 따라 다르다:
     - 상승 카드는 아래에서 위로 올라오고, 띠가 아래에서 위로 찬다.
     - 하락 카드는 위에서 떨어진 뒤 짧게 흔들리고, 띠가 위에서 아래로 내려온다.
   - 동작 줄이기 설정을 켜면 움직임 없이 바로 표시한다.
   - `is-up` / `is-down` / `is-flat` 클래스 이름은 테스트를 위해 그대로 뒀다.
   - 파일: `components/kickx/price-reveal.tsx`, `app/styles/updates-1121b.css`.
3. 스쿼드 버튼 이름
   - `가치 변동 테스트`를 `마지막 변동 확인`으로 바꿨다. 다시 보기 창의 제목도 `마지막 변동 확인`이다.
   - 파일: `components/kickx/squad.tsx`, `tests/price-reveal-browser.mjs`.

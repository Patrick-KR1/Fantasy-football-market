# 10월 15일 서비스 시작 기준 가격 재산정

사용자가 2026-10-30 승인한 초기 가격 범위와 서비스 시작일을 적용한다. 이전의 10월 1일 기준 가격·이력 집계는 과거 작업 기록이며, 이 문서의 기준으로 대체한다.

## 적용 정책

- 서비스 시작: **2026-10-15 00:00 KST** (`2026-10-14T15:00:00Z`).
- 초기 가격: **50,000~150,000P**. 보고서의 포지션 내 백분위 산식을 그대로 사용하며 범위만 사용자가 승인한 값으로 바꾼다.
- 초기 가격 산식: `round(50,000 + 100,000 × percentile(B))`. B는 직전 시즌 유효 경기 점수를 포지션 평균 쪽으로 완화한 기준 점수다.
- Performance 배점은 기존 보고서 기준을 유지한다. 검증된 원천·규칙이 같은 점수는 재사용하고 가격 경로를 다시 계산한다.
- 서비스 시작 전의 현재 시즌 출전도 보고서의 시즌 누적 C에 포함한다. 가격은 초기값에서 출발하며 **시작 시각 이후 종료된 정규 리그 경기만** 변동을 발행한다. 시작일 이전 경기의 가격 변동을 이어 붙이지 않는다.
- 경기가 14일에 시작했어도 15일 00:00 KST 이후 종료됐다면 가격 변동 대상이다. 초기 차트 점은 15일 00:00 KST에 기록한다.
- 경기당 상승·하락 최대 2%, 소속과 미출전이 확인된 선수는 직전 발행 가격의 **−1.5%**. 미출전은 경기력 점수와 출전 분모에 넣지 않는다.
- 기존 완화 계수 λ=5, κ=4, 민감도 β=0.3, s=1, 편차 제한 ±1, 점수 5/95백분위 보정은 유지한다. 전체 발행 가격 범위 10,000~1,000,000P도 유지하므로 경기 결과에 따라 현재가는 초기 가격 범위 밖으로 움직일 수 있다.

현재 사이트의 5대 정규 리그 시장 대상 선수를 초기화한다. 초기값·현재가·경기별 가격 결과·가격 차트를 교체하고, 종속 자산 평가와 랭킹을 갱신한다. 범위 밖 선수의 과거 원천과 추가 대회 일정은 보존한다.

기존 거래 영수증, 지갑 잔액, 보유 취득 원가는 유지한다. 직전 가격 데이터와 정책·자산 평가를 비공개 압축 백업한 뒤 내려받아 SHA-256이 일치하는지 확인한다. 백업 경로·금융 데이터 무결성·정책 입력이 일치할 때만 초기화를 실행한다.

새 기준을 적용한 뒤에는 기존 수집·자동 계산도 같은 시작일과 가격 범위를 사용한다. 다시 실행해도 같은 미출전이 추가로 차감되지 않는다. 대량 재산정은 DB 안에서 검증된 점수를 재사용하고 15명씩 처리하여 경기 API 재호출과 원천 전송을 줄인다.

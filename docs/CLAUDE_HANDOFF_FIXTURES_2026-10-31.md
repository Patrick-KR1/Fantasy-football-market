# Claude 인계: 경기 일정 접기와 산정 상태

2026-10-31 경기 일정 페이지 추가 수정이다. 기존 5대 정규 리그 일정 범위, 구단 상세의 전체 대회 일정, 오늘 위치 자동 스크롤을 이어서 사용한다.

## 날짜별 접기

- 날짜 제목 전체가 접기·펼치기 버튼이다. 경기 수와 방향 아이콘을 함께 표시한다.
- 연·월 제목 영역 오른쪽에 `모두 접기`, `모두 펼치기`를 추가했다. 좁은 화면에서는 제목 아래 오른쪽에 배치한다.
- 기본은 한국 시간으로 오늘을 포함한 최근 7일만 펼친다. 예를 들어 10월 31일에는 10월 25~31일이 대상이다. 이전 날짜와 미래 날짜는 접힌다. 선택한 월에 속하는 날짜만 표시한다.
- 월을 바꾸거나 `최신`을 누르면 기본 펼침 범위로 돌아간다. 리그·구단 검색·경기 상태 필터를 변경하는 동안에는 사용자가 설정한 펼침 상태를 유지한다.
- 키보드 Enter·Space, `aria-expanded`, `aria-controls`, 실제 숨김 영역을 지원한다. 접힌 경기의 링크는 키보드 탐색과 화면낭독기에서 제외된다.

## 계산 대기가 많았던 원인과 수정

기존 `kickx_fixture_reflection()`은 해당 경기의 결과 외에 선수의 전체 시장 스냅샷 `pricing_status`를 읽었다. 선수가 다른 경기의 원천 충돌 때문에 가격 발행 보류에 걸리면 이미 점수가 계산된 경기까지 `계산 대기`로 표시됐다.

이제 해당 경기의 `performance_results`만으로 점수 산정 상태를 판정한다. 확인된 미출전 결과도 처리 완료 결과에 포함한다. 기존 `(fixture_id,status,player_id)` 인덱스를 이용한 제한 조회로 상태를 확인하며 새 테이블·인덱스를 추가하지 않는다.

| 표시 | 의미 |
| --- | --- |
| 점수 산정 대기 | 이 경기의 산정 결과가 아직 없음 |
| 기록 확인 필요 | 결과가 모두 필수 원천 충돌 등으로 보류됨 |
| 일부 점수 산정 | 완료된 결과와 보류된 결과가 함께 있음 |
| 점수 산정 완료 | 저장된 경기별 결과가 산정 완료됨 |

경기별 점수 산정 상태와 선수별 가격 발행 상태는 다르다. 경기 배지에 가격 전체 반영을 보장하는 문구를 넣지 않는다. 서비스 시작 전 경기는 평가 자료로 쓰이지만 경기별 가격 변동 발행 대상은 아니며, 다른 경기의 보류가 현재가 발행을 막을 수도 있다. 툴팁에서 이 구분을 설명한다.

## 운영 DB 확인 결과

10월 일정 168경기 중 종료 경기는 159경기였다. 수정 전에는 대기 105·완료 14·일부 38·보류 2였으나, 경기별 점수 판정 수정 후에는 **완료 119·일부 38·기록 확인 필요 2**다. 나머지 9경기는 종료 상태가 아니므로 산정 배지가 없다. 이후 원천 갱신에 따라 숫자는 바뀔 수 있다.

실제 확인이 필요한 40경기의 보류 결과는 VAR 기록 105건/2경기, 출전 시간 불일치 35건/34경기, 교체와 상대 득점의 시각 선후 불명확 9건/5경기다. 여러 사유가 같은 경기에서 겹칠 수 있다. 이 기록은 임의의 점수로 바꾸지 않았다. 공급자 정정이나 명확한 추가 근거가 있어야 재산정할 수 있다.

이번 작업은 가격·퍼포먼스 수식, 선수별 점수, 가격 이력, 거래 원장을 재산정하지 않는다. 배지 판정 함수와 화면 표시를 수정한 것이다. 운영 DB에 함수 수정을 적용하고 실제 분포를 다시 조회했다. `SECURITY INVOKER`와 기존 역할별 실행 권한을 유지한다.

## 파일과 검증

- `components/kickx/fixtures.tsx`: 날짜별·전체 접기, 최근 7일 기본값, 산정 배지 문구.
- `app/styles/calendar-board.css`: 연월 영역의 접기 버튼과 반응형 배치.
- `supabase/migrations/20261031110255_fixture_scoring_status.sql`: 경기별 점수 상태 판정 함수.
- `tests/database-fixture-reflection.sql`: 다른 경기 가격 보류의 영향 차단, 미출전 처리, 일부 보류, 비로그인·로그인 읽기 권한.
- `tests/browser-smoke.mjs`: 최근 7일 경계, 전체·개별 접기, 키보드 조작, 최신 이동, 구단 상세의 컵 일정 유지.

ESLint, 프로덕션 빌드·타입 검사, 전체 migration 적용 후 산정 상태 SQL 검증을 통과했다. 일정에 대한 별도 브라우저 검증은 PC 1440px·태블릿 800px·모바일 390px에서 통과했다. 전체 브라우저 회귀 실행은 변경과 무관한 관리자 사용자 페이지의 `networkidle` 대기 시간 초과가 있어 전체 통과로 기록하지 않는다.

### 5번 스쿼드 첨부 방식

- 서버가 작성자의 저장된 스쿼드(`squads` 테이블, 본인 읽기 권한)를 읽어 본문 끝에 `[[kickx-squad:4-3-3:id,…]]` 표시를 붙인다. 요청 값을 믿지 않는다.
- 사용자가 본문에 직접 입력한 표시는 서버가 항상 지우므로 남의 스쿼드를 꾸며 붙일 수 없다.
- DB 구조와 RPC는 바꾸지 않았다.
- 본문 3,000자 제한에 표시 길이도 포함된다. 넘으면 `스쿼드를 첨부하려면 내용을 조금 줄여 주세요.`를 보여 준다.
- 화면의 모든 본문 출력(상세, 목록 제목 대체, 내 활동)에서 표시를 지우고 카드로 보여 준다.
- 수정할 때 첨부를 유지하면 수정 시점의 스쿼드로 다시 붙는다.
- 단위 테스트를 추가했다: `tests/squad-attachment.test.mjs`.

### 7번 "확인한 변동" 기록

- 이 브라우저의 localStorage에 선수별로 서버의 `가격|변동률`을 기억해 같은 변동을 다시 보여 주지 않는다.
- 연출 여부만 결정하며, 가격 계산은 하지 않는다.
- localStorage `kickx:price-reveal=off`이면 연출을 끈다. 자동 브라우저 검사에서 사용한다.

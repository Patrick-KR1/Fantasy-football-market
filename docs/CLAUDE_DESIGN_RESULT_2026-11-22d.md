# KICK-X 클로드 작업 결과: 네임태그 통일 (2026-11-22 4차)

기준: `main` `84f8ba0`. DB 변경 없음.

- 모든 네임태그(랭킹, 마이페이지, 커뮤니티 목록·글·댓글, 작성자 페이지)를 헤더 오른쪽 네임태그와 같은 모양·크기로 맞췄다.
  - 모양: 판 안의 메인 응원 구단 엠블렘, 흰 테두리, 오른쪽 장식.
  - 크기: 1440px 기준 글자 16px·높이 38px. 860px 이하 13.5px, 480px 이하 12px로 헤더와 같이 줄어든다.
  - 폭: 내용 길이에 맞춘다. 커뮤니티용 최소 폭(150~240px)은 없앴다. 7자 이상 닉네임은 앞 6자 + `…`(전체 이름은 툴팁).
- 네임태그가 없는 회원의 이름도 헤더와 같은 흰 알약(엠블렘 포함)으로 맞췄다.
- 사용자 선택에 따라, 지난 회차에 프로필 아이콘 자리에 따로 두었던 메인 구단 엠블렘은 없앴다. 엠블렘은 네임태그 안에만 보인다. 마이페이지 상단의 빈 아이콘 칸도 정리했다.
- 상점 미리보기 네임태그(`is-preview`)는 상품 소개용이라 큰 크기를 유지한다.

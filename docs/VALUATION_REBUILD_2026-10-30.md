# 10월 1일 기준 가치 재산정 준비와 데이터 점검

2026-10-30 KST. 최신 5대 리그 보완 설계 보고서와 사용자의 미출전 −1.5% 추가 지시를 기준으로 작성했다.

## 적용 상태

코드와 검증은 PR #32에 있다. 운영 DB migration과 가격 교체는 아직 실행하지 않았다. 자동 승인 검토에서 운영 스키마·정책·가격 이력 교체의 명시적 승인을 요구했다. 따라서 이 문서는 운영 반영 완료 보고가 아니다.

기존 거래 영수증, 지갑 잔액, 보유 취득 원가를 소급 변경하지 않는다. 점수·현재가·가격 이력과 이에 종속된 자산 평가 이력/랭킹이 재산정 대상이다. 기존 결과는 비공개 압축 백업을 업로드하고 다시 내려받아 SHA-256을 검증한 다음에 교체한다.

## 보고서와 코드의 대조

이전 시즌 포지션 평균 보정 B, 포지션 내 백분위 초기 가격, 시즌 전체 출전의 완화 누적 C, 초기 가격×지수식 목표가격, 경기당 ±2% 한도는 기존 코드에도 있었다. 운영 활성 정책은 여전히 이전 방식이며, 이전 시즌 기준 자료가 1,100/1,757경기 준비된 상태다.

이번에 수정한 부분은 다음과 같다.

- 서비스 시작은 2026-10-01 00:00 KST다. 이전 시즌으로 초기 가격을 정하고, 시작 이전의 현재 시즌 출전도 누적 경기력에는 포함한다. 가격 발행 이력은 시작 시각의 초기 가격과 이후 종료 경기만 기록한다.
- 보고서의 미출전 가격 유지 제안은 사용자의 최신 지시로 대체한다. 해당 경기의 구단 소속과 미출전이 확인되면 직전 가격에 0.985를 곱해 정수 반올림한다. 예: 100,000 → 98,500 → 97,023P. 전체 최저 가격 10,000P를 지킨다.
- 미출전은 경기력 0점으로 누적하지 않는다. 점수 합계와 출전 수를 그대로 두고 가격만 하락시킨다. 통계 누락/불명확한 출전을 미출전으로 바꾸지 않는다.
- 가격 계산은 경기 종료 순서와 경기 ID로 고정한다. 가까운 실시간 종료 확인 시각이 있으면 사용하고, 과거 경기에 종료 시각이 없으면 검증된 경기 길이와 휴식시간으로 추정한다. 최초 수집 시각을 과거의 실제 종료 시각으로 쓰지 않는다.
- 기존 가격 그래프의 재산정 실행 시각 대신 서비스 시작점과 각 경기 종료 기준의 이력을 만든다. 같은 입력 재실행은 −1.5%를 추가로 적용하지 않는다.
- 컵·유럽 대회는 새 정책의 점수·가격에서 제외한다. 구단 상세의 추가 대회 일정 열람은 유지한다.

λ=5, κ=4, β=0.3, 분모 하한 s=1, 편차 제한 ±1, 초기/전체 가격 10,000~1,000,000P, 극단값 보정 5/95백분위 등 이미 선택한 계수는 유지했다.

## 과거 소속과 미출전의 한계

과거 경기의 확정 벤치 명단·결장자 명단·그 시점 이전에 확보된 선수단 관측으로 소속이 입증되는 경우만 하락을 적용한다. 현재 스쿼드를 과거 경기로 소급 복사해 모든 선수를 결장 처리하지 않는다.

새 소속 관측은 스쿼드가 바뀔 때만 작은 ID 목록을 추가하고, 같으면 마지막 확인 시각만 갱신한다. 과거에 벤치/결장자 목록에도 없고 당시 소속 관측도 없는 선수의 미출전 여부는 데이터만으로 확정할 수 없다. 이 경우 임의의 −1.5%를 만들지 않는다.

## 운영 적용 순서

1. 명시적인 운영 변경 승인 확인.
2. migration 적용. 이 단계에서 백업·기준 자료·호환 배포 확인 없이 새 가격을 활성화하지 않는다.
3. 최신 팀/스쿼드/전체 일정 대조와 일반 수집 경로를 통한 누락·소속 보완.
4. 기존 점수·가격·초기가격·평가/랭킹 이력을 비공개 압축 백업하고 복구 바이트 검증.
5. 이전 시즌 1,757경기를 끝까지 확보하고 네 포지션 모집단을 확정. 준비 중인 1,100경기만으로 가격을 임의 확정하지 않는다.
6. 호환 코드 배포 확인 후 초기 가격을 새 기준으로 설정하고 자동 계산 큐로 경기 결과를 재생.
7. 보류 선수/누락/무결성 검사, 거래·잔액·취득 원가 보존 확인, 자산 평가 이력과 랭킹 갱신.

과거 자료 수집은 기존 공유 API 예산과 라이브 경기 여유를 지킨다. 호출 한도나 공급자 자료 불일치가 남으면 중단 지점에서 재개하며, 완료되지 않은 작업을 완료로 표시하지 않는다.

## 검증

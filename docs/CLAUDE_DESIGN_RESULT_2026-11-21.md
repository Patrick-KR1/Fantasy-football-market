테마별 장식:

- 네임태그
  - 오로라 드라이브: 빛 궤적과 반짝임, 판 색이 천천히 흐른다.
  - 아케인 크라운: 수정 왕관 장식, 엠블렘 위 작은 왕관.
  - 제로 서킷: 회로와 번개, 판 아래 전류가 흐른다.
  - 인페르노: 흔들리는 불꽃, 엠블렘 위 불씨.
- 기존 선수 테두리
  - 승리의 월계관: 월계 잎 화환과 리본.
  - 네온 코어: 전류가 흐르는 회로선과 노드. 아래쪽 회로는 이름과 겹쳐 지웠다.
  - 룬 크리스털: 수정 다섯 조각과 천천히 도는 룬 고리.
- 경기장 주변 물체
  - 올림포스: 신전 기둥.
  - 메카 그리드: 회전 기어와 기계 장치.
  - 윈터 빌리지: 크리스마스트리와 선물 상자.
  - 마그마 아레나: 용암이 갈라진 바위와 불씨.
  - 스타라이트: 고리 행성, 초승달, 별.

오른쪽 위 계정 영역의 가독성:

- 포인트를 검은 알약 + 노란 `P` 칩으로 바꿨다. 1440px 헤더 오른쪽 사진 위에서 검은 글씨라 읽을 수 없던 문제다.
- 네임태그를 장착하지 않은 회원의 이름에는 밝은 알약 배경을 깔았다.
- 긴 닉네임은 말줄임으로 처리해 엠블렘이나 장식과 겹치지 않는다.

## 3 검증

- `npm run lint` 통과, `npm test` 299/299, `npm run test:db` 42개 통과, `npm run build` 성공.
- 브라우저 테스트 10개는 모두 실패한다. `main` `66717b3`에서도 **같은 줄, 같은 오류**로 실패하는 것을 확인했다.
  - 대부분은 `networkidle` 대기 시간 초과다.

  - 미션·상점·뽑기 기능이 들어간 뒤 테스트가 새 API(`/api/kickx/shop`, `/api/kickx/engagement`)를 가짜 응답으로 처리하지 않는 것과 관련 있어 보인다. 브라우저에서 `/api/kickx/shop` 요청이 끝나지 않는 것을 한 번 봤지만 다시 재현되지는 않았다. 테스트 쪽 정리가 필요하다.

# Claude 인계: 선수 시장 범위와 탐색 통합

2026-10-31 사용자 요청 기준. 기존 로고·전체 폭 레이아웃·홈 영문 문구·페이지 입력 카드 등 앞서 Claude가 반영한 디자인을 유지하면서 선수 시장을 수정했다.

## 1. 집계 범위 수정

등록 선수 목록은 이미 5대 정규 리그로 제한됐지만, 시장 배너는 전체 구단·대회 사전을 세고 있었다. 기존 거래 가능 인원은 DB 전체에서 가격이 있는 선수를 세면서 가격 확정 여부도 확인하지 않았다.

| 항목 | 수정 전 | 수정 후 확인값 |
| --- | ---: | ---: |
| 정규 리그 | 14 | 5 |
| 구단 | 223 | 96 |
| 등록 선수 | 2,901 | 2,901 |
| 거래 가능 선수 | 3,260 | 2,553 |

수정 후 수치는 2026-10-31 18:25 KST DB 확인 기준이며 이후 수집·가격 확정·경기 상태에 따라 바뀐다. 숫자를 화면에 고정하지 않는다.

시장 배너의 구단 수, 리그 수, 리그 선택 타일은 현재 소속 구단의 리그가 `bsd-1`, `bsd-3`, `bsd-4`, `bsd-5`, `bsd-6`인 범위로 표시한다. 컵대회와 유럽 대회 타일은 선수 시장에 표시하지 않는다. 다른 구단의 상세 정보를 읽는 데 필요한 전체 구단·대회 사전은 유지한다.

## 2. 거래 가능 선수의 의미

`kickx_market_summary()`가 등록 선수와 같은 범위를 집계한다. `totalPlayers`는 그 범위 전체, `readyPlayers`는 가격이 있고 `pricing_status='ready'`이며 선수 거래 정지가 없는 인원이다. `pricedPlayers`는 여기서 경기 전후 거래 제한에 걸린 인원을 제외한 값이다.

경기 제한은 기존 주문 검사와 같은 기준을 사용한다. 정규 리그 경기 시작 90분 전부터 종료 확인 후 10분까지이며, 구단 또는 해당 경기 통계에 나타난 선수와 연결한다. 집계는 활성 경기를 한 번에 찾고 제한 선수를 묶어서 계산한다. 선수마다 전체 경기 목록을 재조회하지 않는다.

시장 전체 거래량과 상승·하락 집계도 동일한 선수 범위를 사용한다. 상승·하락에는 가격 산정이 완료된 선수만 포함한다. 이번 변경은 집계 함수 수정이며 선수 가격이나 거래 원장을 다시 산정하지 않는다.

화면에는 `전체 N명 · 거래 제한 제외`를 표시한다. 회원별 잔액·중복 보유 등 개별 주문 조건은 기존 주문 단계에서 확인한다.

## 3. 문구 수정

- 배너의 `실제 경기 기록으로 움직이는 선수 가치. 관심 선수를 모아두고 가치가 열리는 순간을 기다리세요.` 문장을 삭제했다.
- `최근 움직임`을 `최근 변동`으로 바꿨다.
- 영문 보조 제목과 한글 제목의 기존 형식을 유지했다.

## 4. 선수 탐색을 시장으로 통합

헤더 보조 메뉴와 푸터에서 선수 탐색 링크를 제거했다. 공통 검색, 홈 관심 선수, 상세 페이지의 목록 복귀, 규칙 안내, 선수 커뮤니티의 목록 진입 링크는 `/market`으로 이동한다.

`/players`는 `/market`으로 영구 리디렉션한다. 기존 링크의 `q`, `team`, `watchlist` 등 쿼리를 유지한다. `/players/[id]` 선수 상세 페이지와 `/api/kickx/players` 데이터 API는 기존 경로를 사용한다. 선수 커뮤니티의 옛 목록 경로도 시장으로 연결한다.

선수 시장에 보유 선수 탭을 추가해 기존 탐색에서 제공하던 보유 조건을 사용할 수 있다. 관심·보유 목록도 시장에서 조회할 때 5대 리그 범위를 적용한다. 일반 목록은 기존처럼 서버 페이지 단위로 읽고, 개인 목록의 인증과 캐시 분리를 유지한다.

## 5. 주요 파일

- `components/kickx/players.tsx`: 배너 집계·타일·문구·보유 탭.
- `components/kickx/shell.tsx`: 메뉴·푸터·공통 검색.
- `next.config.ts`, `app/players/page.tsx`: 옛 탐색 주소 리디렉션.
- `server/kickx/catalog-pages.ts`: 개인 목록을 포함한 시장 리그 범위.
- `supabase/migrations/20261031091852_market_scope_summary.sql`: 운영 DB에 적용한 집계 함수.
- `tests/database-market-scope.sql`: 범위·가격 준비 상태·정지·경기 제한·컵 제외 검증.
- `tests/browser-smoke.mjs`: 시장 범위 표시와 탐색 주소의 조건 유지 검증.

## 6. 확인 결과

단위 테스트 245개, SQL 통합 검사, ESLint, 프로덕션 빌드·타입 검사를 통과했다. 운영 집계의 등록 선수 수는 실제 범위 내 선수 목록 수와 같은 2,901명이었다.

26개 경로의 데스크톱·모바일 브라우저 검증을 통과했다. 시장 타일에 컵대회가 노출되지 않는지, 범위 내 구단·리그 수가 맞는지, 탐색 주소의 검색·관심·구단 조건이 시장으로 전달되는지 확인했다. 브라우저 JavaScript 오류는 없었다.

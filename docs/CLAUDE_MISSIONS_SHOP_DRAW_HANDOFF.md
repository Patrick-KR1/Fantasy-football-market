# KICK-X 미션·상점·선수 뽑기 인계

2026-11-19. 메인 서비스는 팀 배포 https://fantasy-football-market.vercel.app 이며, 팀 저장소는 https://github.com/Patrick-KR1/Fantasy-football-market 의 main이다.

## 구현 범위

- `/missions`: 출석 고정 + 후보 5개 중 매일 무작위 2개. 세 미션 완료 후 1,000P 수령. 배정은 계정·한국 날짜별로 고정되며 새로고침으로 바뀌지 않는다.
- 주간은 한국 시간 화요일 00:00~다음 화요일 00:00. 출전 7명, Performance 10점 이상 1명, 수동 매각 1회, 일일 전체 클리어 5일, 글·댓글 10회, 출석 7일 완료 후 10,000P를 수령한다.
- 금요일 00:00~화요일 00:00 사이 5대 정규리그 경기 0개면 출전·고득점 미션이 AI 리포트 10회·시세 10회로 바뀐다. 취소·연기 경기는 경기 수에서 제외하며, 최신 수집 일정으로 판단한다.
- 출전은 경기 시작 시점의 선발 보유 상태, 고득점은 경기 시작 시점의 보유 상태를 기준으로 한다. 벤치 선수도 고득점 대상에는 포함한다. 기능 적용 이전의 선발 이력은 복원하지 않으므로 과거 경기의 미션 실적을 소급하지 않는다.
- AI 설명이 실제 표시되는 리포트를 집계한다. 같은 리포트·같은 선수 시세는 대상별 하루 1회만 반영한다. 게시글·댓글은 새 작성만, 관심 등록은 실제 신규 등록만 집계한다. 벤치 자동 매각·중복 뽑기의 포인트 전환은 매각 미션에 포함하지 않는다.
- `/shop`: 네임태그 4종, 선수 아이콘 테두리 3종, 경기장 5종, 출석 복구권. 구매와 장착을 분리하고 보유한 치장은 재구매하지 않는다. 복구권은 중복 구매 가능하다.
- 로그인 전에도 `/api/kickx/shop`의 공개 카탈로그로 상품 디자인·가격과 전체 추첨 대상 수를 미리 보여준다. 개인 보유 정보·미션 진행·구매 API는 공개하지 않는다.
- `/squad`: 유니폼/선수 얼굴 무료 전환. 상품이 아니며 포인트가 차감되지 않는다. 구매한 테두리와 경기장 테마를 실제 피치에 적용한다.
- 네임태그는 계정 메뉴·마이페이지·커뮤니티 작성자·댓글·랭킹에서 회원 ID를 기준으로 표시한다. 타 회원 정보는 한 번에 묶어 조회하고 캐시한다.
- `/draw`: 100,000P, 한국 날짜당 1회. 5대 리그 소속·포지션 확인·거래 가능·가격 산정 완료 선수 전체를 동일 확률로 추첨한다. 보유 중인 선수와 경기 거래 제한 중인 선수도 확률 모집단에 포함한다.
- 중복 보유는 기존 정책대로 허용하지 않는다. 이미 보유한 선수를 뽑으면 뽑기 당시 시세에서 기존 매각 수수료를 뺀 포인트로 전환한다. 재추첨하지 않는다.
- 뽑기 결제와 결과는 서버에 먼저 저장한다. 미배치 결과가 있으면 다음 뽑기를 막고, 새로고침 후에도 같은 결과의 배치를 이어간다. 선발 정원이 차면 새 선수 또는 기존 선수를 벤치로 보낸다. 포지션 정원이 찬 경우 같은 포지션만 교체 가능하다.
- 경기 거래 제한 중인 새 선수는 벤치 보관만 가능하고, 거래 제한 중인 기존 선수를 밀어낼 수 없다. 기존 벤치의 현재 시세·7일 보관·매각/복귀 규칙을 그대로 사용한다.

## 현재 설정한 상점 가격

| 분류 | 상품 | 가격 |
|---|---|---:|
| 네임태그 | 오로라 드라이브 | 12,000P |
| 네임태그 | 아케인 크라운 / 제로 서킷 | 각 18,000P |
| 네임태그 | 인페르노 | 25,000P |
| 테두리 | 승리의 월계관 / 네온 코어 / 룬 크리스털 | 8,000 / 12,000 / 15,000P |
| 경기장 | 올림포스 / 메카 그리드 / 윈터 빌리지 / 마그마 아레나 / 스타라이트 | 각 30,000P |
| 소모품 | 출석 복구권 | 2,000P |

가격은 사용자 미지정 부분에 설정한 초깃값이다. 운영 가격은 `kickx_private.shop_items`에서 변경한다. RPC는 클라이언트가 보내는 가격을 신뢰하지 않는다. 가격 조정 시 후속 마이그레이션으로 이력도 남긴다.

복구권은 이번 주의 **지난 결석일**에만 사용한다. 가입 이전 날짜, 오늘, 미래, 이전 주에는 사용할 수 없다. 주간 출석만 복구하고 과거 일일 미션이나 일일 보상을 소급하지 않는다. 미수령 일일 보상은 완료 후 7일 동안 받을 수 있다.

## 디자인 보완 요청

현재 검정·노랑의 기존 사이트 테마에 맞춰 실제 동작하는 기본 디자인을 구현했다. 참고 이미지의 블리자드 로고나 아트는 포함하지 않았다. 네임태그는 CSS 배경·프레임·문장 장식 전체를 바꾼다. 경기장도 이름만 바꾸는 대신 각각 대리석/금색, 청록 회로, 눈/조명, 용암 균열, 성운/별빛 표면을 사용한다.

추가로 다듬을 부분:

1. 네임태그별 고유 문장·날개·전류·룬의 정교한 SVG. 현재는 별 문장과 CSS 장식이며 프리미엄 아트 수준의 개별 제작은 남아 있다.
2. 월계 테두리를 실제 잎 모양 SVG로 교체하고, 회로·크리스털 테두리의 모서리 장식을 보강한다.
3. 경기장별 주변 오브젝트(신전 기둥, 메카 장치, 크리스마스트리, 암석, 천체)를 추가한다. 선발 선수·이름·포지션 선택을 가리지 않도록 한다.
4. 뽑기 공개 애니메이션·사운드는 선택적으로 보강한다. 미리 정해진 **서버 결과**를 공개하는 연출이어야 하며 클라이언트가 추첨하지 않는다. `prefers-reduced-motion`을 지킨다.
5. 로그인한 실제 브라우저에서 긴 닉네임, 390/768/1440px 화면, 모든 테마·벤치 결과를 시각적으로 검수한다. 로컬 브라우저 실행이 환경 제한으로 실패했으므로 스크린샷 검수가 완료됐다고 간주하지 않는다.

레이아웃·애니메이션을 변경할 때 결제 요청의 `requestId`, 보상/출석/미션 판단, 한국 시간 경계, 대상 선수가 동일 확률이라는 조건은 유지한다. 새로고침을 재추첨으로 바꾸거나 얼굴 표시를 유료화하지 않는다.

## 정산·검증 메모

- 포인트 차감/지급/아이템 소유권/뽑기는 DB 트랜잭션 안에서 기존 경제 잠금을 사용한다. 사용자 입력으로 진행 수나 포인트를 올리는 API는 없다.
- 비공개 테이블은 RLS를 켜고 멤버의 직접 읽기/쓰기를 막았다. 내부 함수도 공개 실행 권한이 없다.
- 미션 보상과 치장 상품 지출은 실제 잔액·총자산에는 반영되지만 거래 수익률에서 제외한다. 뽑기 자체의 손익은 반영한다.
- 미배치 뽑기 결과는 100,000P의 대기 자산으로 포함하고, 배치 후 실제 선수 시세로 평가한다. 결제와 배치 때 포인트를 두 번 차감하지 않는다.
- 활동 이력은 계정별 하루 첫 접근 때 35일 이전분을 정리한다. 출석·일일 미션 상세는 90일 유지한다. 정산 원장은 삭제하지 않는다. 보유 이력은 오래된 기준 상태 하나를 남겨 미래 경기의 보유 시점 판정에 사용한다.
- `npm test`, `npm run test:db`, `npm run lint`, `npx tsc --noEmit`, `npm run build`로 확인한다. DB 테스트는 PGlite의 폐기 가능한 환경만 사용하며 실제 사용자 포인트로 시험하지 않는다.
- 실제 Google OAuth 로그인부터 결제까지의 브라우저 검증은 별도로 필요하다. 서버 정산·권한 검증과 화면 시각 검증을 구별한다.

운영 DB 적용 버전: `20261119042710`. 신규 비공개 테이블의 RLS 무정책은 직접 접근을 막기 위한 의도된 상태다. 공개 네임태그 RPC는 장착한 네임태그 ID만 반환하며 최대 100명으로 제한한다. 관련 점검 기준: https://supabase.com/docs/guides/database/database-linter?lint=0028_anon_security_definer_function_executable

공개 상품 미리보기 추가 버전: `20261119045023_public_shop_preview.sql`. 비로그인 환경의 실제 팀 배포 페이지에서 기본 레이아웃을 확인했다. 로그인한 계정의 구매·장착·뽑기 흐름과 모바일 시각 검수는 별도 항목이다.

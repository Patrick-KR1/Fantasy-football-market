# Claude 디자인 인계: 홈과 공통 헤더

기준일: 2026-10-31. 이번 변경은 사용자가 첨부한 홈 화면의 수정 항목을 반영한 것이다. 공통 헤더 변경은 홈 외의 페이지에도 적용된다.

## 1. 반영한 화면 변경

### 1-1. 공통 헤더

- 검은 상단 바의 왼쪽 `KICK-X / FOOTBALL MARKET` 문구를 삭제했다.
- 오른쪽 `가상 포인트 전용 서비스` 문구를 삭제했다.
- 상승·하락 선수 수, 경기 확인 시각, 가격 적용 시각은 가운데 정렬했다. 좁은 화면에서는 정보가 줄바꿈된다.
- 노란색 영역의 KICK-X 로고, 메뉴, 계정 메뉴는 기존 구조를 사용한다.

구현: `components/kickx/shell.tsx`, `app/styles/shell.css`.

### 1-2. 홈 선수 목록 하단

- 목록 아래의 `가격 적용 … · 가치와 Performance는 KICK-X 내부 지표입니다.` 안내 문장을 삭제했다.
- 데스크톱에서는 표시 범위와 전체 선수 수를 왼쪽에 두고, 페이지 버튼은 목록 전체 폭의 중앙에 배치했다.
- 700px 이하에서는 표시 범위를 위에, 페이지 버튼을 아래 중앙에 배치한다. 공간이 부족하면 버튼이 줄바꿈된다.
- 한 페이지에 선수 10명을 표시하는 기존 조회 방식을 사용한다.

구현: `components/kickx/home.tsx`, `components/kickx/pagination.tsx`, `app/styles/calendar-board.css`.

### 1-3. 페이지 번호 직접 입력

페이지 사이의 `…`는 클릭 가능한 버튼이다. 누르면 페이지 버튼 아래에 다음 항목이 열린다.

- 이동할 페이지 입력칸. 현재 페이지가 선택된 상태로 입력에 초점이 간다.
- 전체 페이지 수.
- `이동`, `취소` 버튼.

번호를 입력하고 Enter 또는 `이동`으로 이동한다. 첫 페이지부터 마지막 페이지 사이의 정수만 허용한다. 빈 값, 문자, 소수, 0, 마지막 페이지를 넘는 값에는 안내 문구를 보여주며 데이터를 요청하지 않는다.

`취소` 또는 Escape로 닫으면 눌렀던 `…` 버튼으로 초점을 돌린다. 양쪽 구간 생략 버튼 모두 같은 입력 폼을 연다. 일반 페이지 버튼이나 이전·다음 버튼으로 이동해도 입력 폼을 닫는다.

공용 `Pagination`에 `centered`, `allowJump` 옵션을 추가했고 홈에서 활성화했다. 옵션 기본값은 false이며, 커뮤니티와 경기 일정 등 기존 호출부의 배치는 그대로 사용한다. 새 화면에서 같은 동작을 원하면 두 옵션을 지정하면 된다.

### 1-4. 시세 영역 문구

| 위치 | 적용 문구 |
| --- | --- |
| 작은 상단 문구 | 시세 한눈에 |
| 영역 제목 | 선수 시세 동향 |

기존 `MARKET MOVERS`, `오늘 가장 크게 움직인 선수`를 위 문구로 교체했다. 상승·하락 목록과 최근 내 거래 구성은 기존 데이터를 사용한다.

## 2. 디자인 작업 시 확인할 동작

페이지 번호 입력은 기존 목록의 서버 페이지 조회로 연결된다. 전체 선수를 내려받아 화면에서 잘라 쓰거나, 입력할 때마다 검색 요청을 보내는 방식으로 바꾸지 않는다.

버튼의 `aria-current`, 생략 버튼의 `aria-expanded`, 입력 레이블, 오류 안내, Escape와 초점 복귀를 유지한다. 헤더의 날짜는 데이터 기준 시각이며 페이지를 연 현재 시각으로 대체하지 않는다.

공통 헤더·푸터는 `components/kickx/shell.tsx`, 스타일은 `app/styles/shell.css`에 있다. 홈 주요 영역은 `components/kickx/home.tsx`에서 이어서 작업할 수 있다.

## 3. 검증

- ESLint 통과.
- 프로덕션 빌드와 TypeScript 검사 통과.
- 데스크톱 1440px·모바일 390px 브라우저 검증 통과. 홈의 직접 이동·오류 안내·첫/마지막 페이지·키보드 닫기·취소와 화면 넘침을 확인했다.
- 공통 헤더가 사용되는 화면을 포함해 26개 경로를 두 해상도에서 열었고 브라우저 JavaScript 오류는 없었다.

`tests/browser-smoke.mjs`에 홈 문구, 페이지 버튼 중앙 정렬, 잘못된 번호의 요청 차단, Enter 이동, 처음·마지막 페이지, Escape·취소, 모바일 입력 폼 검증을 추가했다.

브라우저 검증 시 `test-artifacts/home-page-input-desktop.png`, `test-artifacts/home-page-input-mobile.png`에 화면을 저장한다. 실제 경기 수와 시각은 검증 자료와 운영 환경에서 다를 수 있다.
